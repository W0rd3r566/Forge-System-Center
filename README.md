Forge — настольный центр мониторинга и управления компьютером для **Linux и Windows**. Он объединяет показатели производительности, процессы, накопители, сетевые счётчики, доступные датчики и диагностику в одном интерфейсе на PySide6.

Forge работает локально: нет аккаунта, встроенной аналитики и автоматической отправки системных данных. Настройки и журнал приложения сохраняются в профиле текущего пользователя.

## Настройка интерфейса

Открой раздел **«Внешний вид»**:

- **Темы:** Graphite, Midnight, Emerald и Light.
- **Акценты:** лавандовый, голубой, мятный, розовый, янтарный, коралловый или бирюзовый.
- **Обои:** PNG, JPEG, WebP, BMP и GIF. Изображение остаётся локальным и смешивается с фоном с настраиваемой интенсивностью.
- **Плотность интерфейса:** размер текста, ширина бокового меню и частота обновления.
- **Пользовательские стили:** Qt Style Sheets (QSS) применяются поверх темы. QSS похож на CSS, но использует правила Qt и не поддерживает JavaScript или браузерный DOM.
- **Профили:** настройки можно экспортировать в JSON и импортировать на другом компьютере. Само изображение обоев в профиль не включается, поэтому путь к нему должен существовать и на целевом устройстве.

Пример QSS:

~~~css
/* QSS для интерфейса Qt, а не стиль веб-страницы. */
#panel {
    border-radius: 18px;
    border: 1px solid #423b61;
}
#navButton:checked {
    background: #292440;
    border: 1px solid #a99bff;
}
QPushButton {
    padding: 9px 14px;
}
~~~

Вставь правила в редактор и нажми **«Сохранить и применить»**. Настройки хранятся отдельно от исходников и не изменяют файлы проекта.

## Установка

### Linux · CachyOS, Arch, Ubuntu и другие

Нужен Python 3.10 или новее.

~~~bash
git clone https://github.com/W0rd3r566/Forge-System-Center.git
cd Forge-System-Center
bash install.sh
~~~

Установщик создаёт виртуальное окружение в **.venv**, устанавливает PySide6 и psutil и добавляет пользовательский ярлык. Он не использует **sudo** и не изменяет системный Python.

Запуск и обновление:

~~~bash
bash run.sh
~~~

Для обновления уже клонированного проекта сначала выполни **git pull**, затем **bash run.sh**.

### Windows 10 / 11

1. Установи Python 3.10+ с [python.org](https://www.python.org/downloads/windows/) и включи **Add Python to PATH**.
2. Открой PowerShell в папке проекта.
3. Выполни:

~~~powershell
.\install.ps1
.\run.bat
~~~

Если PowerShell блокирует скрипт, временно разреши выполнение только для текущего окна:

~~~powershell
Set-ExecutionPolicy -Scope Process Bypass
.\install.ps1
.\run.bat
~~~

## Совместимость

| Функция | Linux | Windows |
|---|:---:|:---:|
| Обзор, процессы, накопители | ✓ | ✓ |
| Графики CPU и памяти | ✓ | ✓ |
| Сетевые счётчики и интерфейсы | ✓ | ✓ |
| Температуры, батарея, вентиляторы | Если доступно | Если доступно |
| Данные NVIDIA через nvidia-smi | Если установлен драйвер и утилита | Если установлен драйвер и утилита |
| Пользовательский автозапуск | ✓ | ✓ |
| Службы systemd | ✓ | — |
| Очистка пользовательского кэша Linux | ✓ | — |
| Обои, темы, QSS и профили | ✓ | ✓ |

Датчики зависят от оборудования, драйверов и возможностей ОС. Если показаний нет, Forge сообщает об их отсутствии, а не подставляет выдуманные значения.

## Разработка

~~~bash
python -m venv .venv
~~~

Активируй окружение:

~~~bash
# Linux
source .venv/bin/activate
# Windows PowerShell
.\.venv\Scripts\Activate.ps1
~~~

Затем:

~~~bash
python -m pip install -r requirements.txt
python -m compileall -q forge run.py
python -m unittest discover -s tests -v
python run.py
~~~

GitHub Actions проверяет компиляцию Python, unit-тесты и начальную инициализацию GUI на Linux и Windows.

## Данные и безопасность

- Forge не требует аккаунта, не отправляет телеметрию и не загружает обои или пользовательские стили в сеть.
- Настройки и журнал действий хранятся локально в пользовательском каталоге конфигурации.
- Диагностический отчёт создаётся только по явному действию пользователя и не отправляется автоматически. Он может содержать названия процессов и сведения об оборудовании; перед публикацией проверь файл.
- Forge не повышает права для завершения процессов. Действия со службами и автозапуском требуют подтверждения.
- Очистка ограничена пользовательским кэшем Linux. Документы, загрузки и системные каталоги не удаляются.
