# Максимальная кастомизация Forge

[English version](CUSTOMIZATION.en.md) · [Главная документация](../README.md)

Forge использует **Qt Style Sheets (QSS)**. QSS похож на CSS, но работает с виджетами Qt, а не с HTML-страницей. В нём можно менять цвета, фон, прозрачность, рамки, скругления, отступы, шрифты, выделение, состояния кнопок, таблицы, подсказки, ползунки и полосы прокрутки.

Редактор находится в **«Внешний вид» → «Пользовательский стиль (QSS)»**. Для удобства доступны пресеты **Liquid Glass**, **Soft Acrylic**, **Miku Cyan** и **Minimal**. Можно начать с пресета, поменять несколько строк и нажать **«Сохранить и применить»**. Импорт и экспорт работают с файлами `.qss` и текстовыми файлами `.css`. Стили сохраняются в пользовательском профиле, а не в исходниках.

> Важно: это справочник оформления. Пользовательский QSS влияет на визуальную часть, но не может добавить обработчики событий, новые страницы, анимацию Python или новые функции системы.

## 1. Что можно менять в интерфейсе

Встроенные настройки доступны без написания кода:

| Настройка | Что меняет |
| --- | --- |
| Тема | Graphite, Midnight, Emerald, Light |
| Акцентный цвет | Любой выбранный пользователем цвет |
| Шрифт | Установленное в системе семейство шрифтов |
| Размер текста | 10–24 px |
| Ширина бокового меню | 190–360 px |
| Скругление | Радиус углов карточек, кнопок и полей, 4–28 px |
| Плотность | Компактная, обычная, свободная |
| Обои | Локальное изображение, смешиваемое с фоном |
| Прозрачный фон окна | Переключатель слоя Liquid Glass |
| Плотность матового слоя | Альфа-значение фоновой тонировки, 0–220 |
| Частота обновления | 1000–10000 мс |
| История графиков | 30–360 точек |
| Предупреждения | Пороги CPU, памяти, диска и температуры |
| Мини-монитор | Включение, прозрачность, интервал обновления |
| Системный трей | Сворачивание Forge в трей при закрытии |
| Профили работы | Сбалансированный, Игры, Работа, Тихий режим |
| Профили настроек | Импорт и экспорт JSON |
| QSS | Редактирование, импорт, экспорт и выбор пресета |

Само изображение обоев не включается в JSON-профиль. При переносе профиля на другой компьютер путь к файлу обоев должен существовать и там.

## 2. Имена виджетов и селекторы

В Qt селектор `#panel` выбирает виджет с `objectName("panel")`. Класс `QPushButton` выбирает кнопки. Правила пользовательского QSS применяются поверх встроенной темы и могут переопределять её свойства.

### Основные области

| Селектор | Где используется |
| --- | --- |
| `#root` | Корневой фон окна, в том числе слой обоев |
| `#sidebar` | Боковая панель |
| `#topbar` | Верхняя панель |
| `#breadcrumb` | Название текущего раздела |
| `#statusTag` | Индикатор состояния системы |
| `#brandName` | Название FORGE |
| `#brandSub` | Подпись под названием |
| `#logoMark` | Область логотипа в боковой панели |
| `#sectionLabel` | Маленькая метка группы настроек/раздела |
| `#navButton` | Кнопки навигации |
| `#systemChip` | Карточка локального режима внизу меню |

### Карточки и текст

| Селектор | Где используется |
| --- | --- |
| `#hero` | Большой приветственный блок на главной |
| `#heroOverline` | Маленькая надпись над заголовком hero |
| `#heroTitle` | Заголовок hero |
| `#heroSubtitle` | Подпись hero |
| `#panel` | Обычная панель/карточка |
| `#panelTitle` | Заголовок карточки |
| `#metricCard` | Карточка системной метрики |
| `#metricValue` | Основное значение CPU/RAM и т. п. |
| `#livePill` | Маленькая метка LIVE |
| `#infoValue` | Значение в информационной строке |
| `#bigNumber` | Крупное число в сетевом центре |
| `#muted` | Второстепенный текст |
| `#mutedSmall` | Маленькая подпись |
| `#pathLabel` | Текстовый путь |
| `#greenDot` | Точка локального статуса |

### Кнопки, таблицы и графики

| Селектор | Где используется |
| --- | --- |
| `#quickButton` | Кнопка быстрого действия на главной |
| `#primaryButton` | Основная кнопка действия |
| `#secondaryButton` | Обычная кнопка |
| `#dangerButton` | Опасное действие, например завершение процесса |
| `#dataTable` | Таблицы процессов, дисков, датчиков и интерфейсов |
| `#historyChart` | Кастомно рисуемые графики истории |
| `#customQssEditor` | Редактор QSS и текстовые журналы |
| `#miniMonitorWindow` | Внешнее окно мини-монитора |
| `#miniMonitorCard` | Стеклянная карточка мини-монитора |
| `#miniMonitorTitle` | Заголовок мини-монитора |
| `#miniMonitorReadout` | Значения CPU/RAM/Disk в мини-мониторе |
| `#miniMonitorFooter` | Нижняя подпись мини-монитора |
| `#miniMonitorClose` | Кнопка закрытия мини-монитора |

Часть блоков рисуется вручную через `QPainter`, в частности графики и задний фон. Некоторые свойства таких блоков ограничены кодом отрисовки: QSS сам по себе не превращает нарисованный график в обычный `QFrame`.

## 3. Общие классы Qt

Можно использовать и селекторы по классу виджета:

- `QWidget`, `QMainWindow`, `QFrame`, `QLabel`
- `QPushButton`, `QToolButton`, `QCheckBox`
- `QLineEdit`, `QComboBox`, `QSpinBox`, `QPlainTextEdit`
- `QTableWidget`, `QHeaderView::section`, `QListWidget`
- `QScrollBar:vertical`, `QScrollBar:horizontal`, `QStatusBar`
- `QSlider::groove:horizontal`, `QSlider::handle:horizontal`
- `QProgressBar`, `QToolTip`, `QDialog`, `QMessageBox`

Для элементов внутри виджетов используются субконтролы, например `QComboBox::drop-down`, `QComboBox QAbstractItemView`, `QSpinBox::up-button`, `QSpinBox::down-button`, `QListWidget::item:selected`.

### Состояния

| Селектор состояния | Пример |
| --- | --- |
| `:hover` | Мышь наведена на кнопку |
| `:focus` | Поле получило фокус |
| `:checked` | Выбранная кнопка навигации или чекбокс |
| `:disabled` | Неактивный контрол |
| `::item:selected` | Выбранная строка списка |

## 4. Готовые примеры

### Полупрозрачные карточки

```css
#panel, #metricCard, #systemChip {
    background-color: rgba(28, 30, 46, 155);
    border: 1px solid rgba(190, 179, 255, 110);
    border-radius: 18px;
}
```

### Более светлая активная навигация

```css
#navButton:checked {
    color: #ffffff;
    background-color: rgba(169, 155, 255, 70);
    border: 1px solid rgba(205, 195, 255, 220);
    border-radius: 12px;
}
#navButton:hover {
    background-color: rgba(255, 255, 255, 20);
}
```

### Шрифт и кнопки

```css
QLabel {
    letter-spacing: 0.2px;
}
QPushButton {
    padding: 9px 14px;
    border-radius: 11px;
}
QPushButton:disabled {
    color: #77788a;
    background-color: rgba(100, 100, 120, 35);
}
```

### Градиентный hero-блок

```css
#hero {
    background: qlineargradient(
        x1: 0, y1: 0, x2: 1, y2: 1,
        stop: 0 rgba(105, 88, 170, 210),
        stop: 1 rgba(24, 26, 42, 190)
    );
    border: 1px solid rgba(200, 188, 255, 175);
    border-radius: 22px;
}
```

### Строки таблиц

```css
#dataTable {
    alternate-background-color: rgba(255, 255, 255, 8);
    selection-background-color: rgba(135, 115, 220, 170);
    selection-color: #ffffff;
}
QHeaderView::section {
    padding: 10px;
    color: #bcb8d2;
    background-color: rgba(255, 255, 255, 15);
    border-bottom: 1px solid rgba(190, 179, 255, 90);
}
```

### Скроллбары

```css
QScrollBar:vertical {
    width: 9px;
    background: transparent;
    margin: 2px;
}
QScrollBar::handle:vertical {
    min-height: 24px;
    background: rgba(190, 179, 255, 115);
    border-radius: 4px;
}
QScrollBar::handle:vertical:hover {
    background: rgba(210, 200, 255, 180);
}
QScrollBar::add-line:vertical,
QScrollBar::sub-line:vertical {
    height: 0;
}
```

## 5. Цвета и прозрачность

В QSS можно использовать HEX-цвета, например `#a99bff`, или RGBA:

```css
background-color: rgba(30, 32, 50, 150);
```

Последнее значение альфа-канала находится в диапазоне **0–255**: `0` полностью прозрачно, `255` полностью непрозрачно. На результат влияют фон под виджетом, оконный композитор и тема системы.

### Как настроить Liquid Glass

1. Открой **«Внешний вид»**.
2. Выбери изображение обоев.
3. В QSS-пресетах выбери **Liquid Glass** или **Soft Acrylic** и нажми **«Загрузить пресет»**.
4. Включи **«Прозрачный фон окна»**.
5. Настрой интенсивность обоев и плотность матового слоя. Небольшое значение плотности сильнее показывает фон; большое делает поверхность темнее и читабельнее.
6. Нажми **«Сохранить и применить»**.

**Ограничение:** Qt QSS не поддерживает веб-свойства `backdrop-filter`, `box-shadow`, `transition`, `animation`, `display: flex`, `grid`, CSS-переменные `var(--name)` или JavaScript. Forge создаёт мягкую подложку из выбранных обоев и смешивает её с полупрозрачным окном. Это не гарантирует системное размытие рабочего стола в реальном времени: оно зависит от оконного композитора.

## 6. Что не стоит переопределять без необходимости

- Глобальное правило `QWidget { background-color: ...; }` может залить фоном все вложенные контролы и скрыть прозрачность. Для стекла чаще лучше менять конкретно `#panel`, `#sidebar`, `#topbar`.
- Не задавай непрозрачный фон для `#root` и `QMainWindow`, если хочешь сохранить прозрачный слой.
- Слишком низкий контраст делает значения метрик трудночитаемыми.
- QSS не меняет логику программных действий, правила безопасности или состав доступных датчиков.
- Максимальная длина пользовательского QSS — **30 000 символов**.

## 7. Где хранятся настройки

- Настройки и встроенный QSS сохраняются локально в файле `settings.json` в пользовательском каталоге конфигурации Forge.
- Журналы и история не отправляются автоматически в сеть.
- JSON-профиль переносит параметры и QSS, но не копирует файл обоев.
- Перед экспериментами с крупными изменениями экспортируй профиль. Кнопка отката в диагностике работает только для действий, которые Forge явно пометил как обратимые.
